# ARCFALL credits

ARCFALL's concept and original web prototype belong to the project owner, rooster4166. The native rebuild was developed for this repository with Codex assistance.

## Original production assets

The Blender wizard, first-person staff/hands, imp, tower, bridge, ruins, walls, trees, rocks, meteor, and island were created for this rebuild. Their editable source is `art/blender/arcfall_assets.blend`; `tools/build_art.py` preserves the modeling recipe. Character animations are authored in that source file.

The refined wizard and hands use original sculpted geometry and cloth, leather, brass and walnut maps generated by `tools/build_wizards.py`. Tidewatch Reach is an original closed terrain model in `art/blender/arenas/tidewatch.blend`, with its recipe in `tools/arenas/build_tidewatch.py`.

The twenty-one spell families have additional original models and painted procedural textures in `art/blender/spells/`, with builders in `tools/spells/`. These include the runtime Meteor, Raise Tower, Venom Orb and Stone Wall models. The individual sources, placement contracts and reviewed previews are indexed in `Docs/spell-assets.md`.

The spell icons are original SVG drawings generated by `tools/build_icons.py`. Music and sound effects are original synthesized audio generated by `tools/build_audio.py` and `tools/build_expansion_audio.py`. Terrain, water, and spell visuals use project-authored Godot code and shaders. No downloaded asset pack, Arcanists artwork, character model, soundtrack, or trademark graphic is bundled.

Windows system fonts are used through Godot's SystemFont API. Font files are not redistributed.
